# E时代导航

E时代导航是 E时代社团的统一服务入口，集中展示社团产品、通行证生态和团队站点。

访问网站：[nav.emoera.com](https://nav.emoera.com/)

## 你可以在这里找到

- **产品服务**：快速进入 E时代通行证、云服务、IDE、信任中心等常用服务。
- **通行证生态链**：查看已经接入 E时代统一登录的应用。
- **团队与官网**：访问 ACM 算法团队、E时代团队、妙计实验室和启发实验室等站点。
- **刷题导航**：通过 [/oj/](https://nav.emoera.com/oj/) 查找算法学习、在线评测、竞赛和开发资源。

顶部的「服务导航 / 刷题导航」始终标明当前栏目。两页使用相同的品牌、搜索和卡片样式，保留各服务的彩色图标与分类色；服务页每次进入默认展示融入页面的 3D 模型，也可手动切换列表，刷题页直接提供分类筛选和搜索。手机默认采用低画质 3D，单指滚动页面、双指旋转模型；WebGL 不可用时保留完整列表。键盘操作和减少动态效果偏好均受到支持。

旧的 `/?namespace=oj` 地址会自动跳转到 `/oj/`，旧分类和资源书签保留对应目标。刷题目录合并为一份内容源 `src/oj/OjData.js`，共 28 条资源。
